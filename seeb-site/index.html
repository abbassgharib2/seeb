Questions fréquentes

Avant de choisir votre groupe.

Une autre question ? Réservez un appel, un conseiller vous répond.

Que signifie 66/60 kVA ?

66 kVA est la puissance de secours, disponible pendant les coupures pour une durée limitée. 60 kVA est la puissance continue, que le groupe fournit pendant de longues heures. Si votre groupe tourne tous les jours pendant les délestages, choisissez-le sur sa puissance continue.

Les moteurs sont-ils vraiment d'origine ?

Oui. Nos groupes sont équipés de moteurs Perkins original UK et, selon le modèle, d'alternateurs Mecc Alte d'origine. Venez les inspecter capot ouvert dans nos locaux avant d'acheter.

Comment choisir la bonne puissance ?

Commencez par le calculateur ci-dessus pour une première estimation. Un conseiller vérifie ensuite les démarrages de moteurs, comme les climatiseurs, les pompes ou les chambres froides, qui demandent une réserve de puissance.

Puis-je voir le groupe avant d'acheter ?

Oui. Réservez une visite : nous vous présentons le groupe 66 kVA et les options disponibles dans nos locaux à Dédokpo, Akpakpa.

Le groupe est-il bruyant ?

Nos groupes sont livrés sous capot insonorisé, avec mousse acoustique et grilles d'aération protégées. Nous vous conseillons aussi sur l'emplacement pour limiter la gêne autour de vous.
